# Публичный тестовый запуск ЧСЛ

Приложение готово к обычному Node.js-хостингу. Для постоянной публичной ссылки внешний хостинг всё равно должен один раз принять проект — это нельзя сделать только локальным архивом без аккаунта/подключения к провайдеру.

## Что уже подготовлено

- `render.yaml` — конфигурация Render;
- `railway.toml` — конфигурация Railway;
- `Dockerfile` — универсальный контейнер;
- `Procfile` — fallback-команда запуска;
- `GET /api/health` — health check;
- `CHSL_SOLO_DEMO=1` — включает тестовые турниры: 10 GC, минимум 1 игрок, каждые 2 минуты, примерно на час.

## Переменные окружения

- `PORT` — задаётся хостингом автоматически;
- `CHSL_SOLO_DEMO=1` — тестовый режим;
- `CHSL_SOLO_DEMO=0` — отключить автогенерацию одиночных тестовых турниров;
- `DATA_DIR` — необязательно; путь к каталогу базы `db.json`.

## Проверка после размещения

Открыть `/api/health`. Ожидаемый ответ содержит:

- `ok: true`;
- `version: "1.0.0"`;
- `soloDemoEnabled: true`.

После этого зарегистрировать нового пользователя. В разделе «Действующие» будут турниры с меткой «можно одному».
