РАСПИСАНИЯ

Создать период расписания

В выбранном периоде будет автоматически создано указанное количество турниров, равномерно распределённых по времени. Для администратора нет ограничения «только будущее»: можно указать прошлое, текущее или будущее время. Расписание редактируется только целиком. Турниры, которые уже начались или уже имеют участников, при редактировании не меняются.
